# Badge
A small pill label for status, tags and counts, set in `caption`.

- Default: neutral metadata (*Cebraspe*, *Simulado*), `border-strong` edge and `muted` text.
- `badge-accent`: tags on collections and topics (`accent` on `accent-soft`).
- `badge-danger`: problems the user must look at (*Contestada*). Always a word, not just the colour.
- `badge-count`: a number on a nav item (pending reviews). Hide it at zero.
