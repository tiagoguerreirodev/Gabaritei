# Tabs
Switches between views of the same data. After the navigation rethink no screen needs it (Banco's tabs became filters and Erros e revisões was removed); keep it for a future view switch and don't use tabs where a filter fits. A `role="tablist"` row of `.tab` buttons on a `border` baseline; the selected tab has `aria-selected="true"`, `text` colour, 600 weight and a 2px `accent` underline.

Use at most two to five tabs; for navigation between pages use Nav.
