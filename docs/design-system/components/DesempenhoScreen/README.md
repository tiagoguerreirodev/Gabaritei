# DesempenhoScreen
Desempenho: how the user is doing, from the overall figure down to the topic. Read top to bottom: figures, weakest topics, trend, full table.

Composition: `h1` *Desempenho* with a filter row (area select, period); `ul.stat-cards` led by *Aproveitamento*; *Assuntos mais fracos* (`item-list`, each row with a sparkline, an accuracy badge and *Treinar*, a link to Banco with that topic); *Evolução semanal* (Chart with its note); *Por área, matéria e assunto* (DataTable with an inline order ChoiceGroup and *Exportar CSV*).
