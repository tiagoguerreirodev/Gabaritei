# Card
The surface that groups one topic of a page: a `surface` box with a `border` hairline and `radius-md`, no shadow.

- Put an `h2` first (styled as `heading`). Content flows below.
- `card-wide` for tables and stat grids; `card-compact` for stat tiles in a grid; `card-row` lays out a one-line banner or notice (text left, actions right).
- A stat tile holds `.stat` > `.stat-name` (muted, small) and `.stat-value` (display).
- Don't nest cards, and don't add coloured edges: status belongs to a badge inside.
