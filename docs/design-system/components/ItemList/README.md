# ItemList
Quiet rows inside a card: the per-area meters and waiting packages on Início, weak topics on Desempenho, open attempts. `ul.item-list` with one `li` per item.

- A row is the item's name (it takes the free width), then its figure or meter, then at most one action, all on one baseline.
- `.is-ruled` separates rows with a `border` hairline and gives them more air: use it when rows carry two lines (title in `.item-title`, a muted meta line below) and an action, as for open attempts.
- Label–value pairs are a `dl.facts` instead (Recap, a caderno's details).
- Keep a list short (five to eight rows); a longer one belongs in Banco or Histórico with a Pager.
