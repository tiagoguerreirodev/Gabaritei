# Tabs
Switches between views of the same data (Banco: *Assuntos* / *Cadernos*). A `role="tablist"` row of `.tab` buttons on a `border` baseline; the selected tab has `aria-selected="true"`, `text` colour, 600 weight and a 2px `accent` underline.

Use at most two to five tabs; for navigation between pages use Nav.
